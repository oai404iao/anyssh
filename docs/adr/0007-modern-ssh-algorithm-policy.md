# ADR-0007：默认现代 SSH 算法，Legacy 按 Host 开启

- 状态：Proposed
- 日期：2026-07-25
- 决策人：项目维护者

## 背景

客户端需要兼顾现代 OpenSSH 与旧网络设备。若为兼容性全局启用 SHA-1、DSA、CBC 或旧 KEX，会降低全部连接的安全基线。

## 决策

- 默认优先 ML-KEM/X25519、Curve25519、ChaCha20-Poly1305、AES-GCM、SHA-2。
- 默认禁用 SHA-1、DSA、CBC 和过时 DH Group。
- Legacy Compatibility 只能保存到单个 Host。
- UI 展示弱算法警告和实际协商结果。
- 不提供全局“允许全部旧算法”开关。

## 备选方案

- 完全不支持旧算法：会失去部分网络设备场景。
- 默认启用所有算法：容易发生降级，安全边界不可控。

## 后果

### 正面

- 新连接默认安全。
- 旧设备兼容风险局部化。

### 代价与风险

- 用户配置更复杂。
- 需要测试不同算法组合和错误提示。

## 验证

- 现代 OpenSSH 不触发 Legacy。
- 旧测试服务器必须显式开启 Host 兼容配置才能连接。
- 弱算法使用会在会话详情中可见。
